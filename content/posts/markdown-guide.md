이 글은 Markdown 문법이 화면에 어떻게 표시되는지 보여 주는 예시입니다.

## 제목과 강조

**굵은 글씨**와 *기울임*, `인라인 코드`를 쓸 수 있습니다.

### 목록

1. 첫 번째 항목
2. 두 번째 항목

- 순서 없는 항목
- 또 다른 항목

## 링크와 이미지

[Next.js 공식 사이트](https://nextjs.org)로 가는 링크입니다.

![예시 이미지](/images/sample.svg)

## 코드 블록

```ts
function greet(name: string) {
  return `안녕하세요, ${name}님`;
}
```

## 표

| 항목 | 설명 |
| --- | --- |
| 제목 | 글 맨 위에 표시됩니다 |
| 태그 | 같은 주제의 글을 묶습니다 |

> 인용문은 이렇게 표시됩니다.
